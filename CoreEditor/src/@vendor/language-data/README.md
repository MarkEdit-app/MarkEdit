# MarkEdit-app/language-data

This package contains only the languages that are always bundled and shipped with the app. All other languages are provided through the [MarkEdit-language-data](https://github.com/MarkEdit-app/MarkEdit-language-data) extension.

This directory is derived from [@codemirror/language-data](https://code.haverbeke.berlin/codemirror/language-data) and is released under the [MIT license](https://code.haverbeke.berlin/codemirror/language-data/src/branch/main/LICENSE).
